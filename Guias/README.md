# Guias

Esta pasta reúne materiais de apoio para organizar os estudos, pesquisar soluções e usar ferramentas importantes no dia a dia de desenvolvimento.

## Guias disponíveis

- [Como estudar](./como-estudar.md) — estratégias para manter uma rotina e aprender com prática.
- [Como pesquisar](./como-pesquisar.md) — técnicas para encontrar, avaliar e aplicar informações.
- [Como usar Git](./como-usar-git.md) — orientações para versionar projetos.
- [Como usar GitHub](./como-usar-github.md) — noções para colaborar e publicar projetos.
- [Roadmap de estudo](./roadmap-de-estudo.md) — visão geral para planejar os próximos passos.
- [Checklist de progresso](./checklist-de-progresso.md) — lista para acompanhar a evolução.

Os guias são complementares: adapte as sugestões à sua rotina e consulte os materiais das [trilhas](../Trilhas/README.md) para aprofundar cada assunto.
