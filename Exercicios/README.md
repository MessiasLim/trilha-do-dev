# Exercícios

Esta pasta reúne atividades para praticar os conceitos estudados nas trilhas. Resolva os exercícios por etapas e, quando possível, compare diferentes abordagens.

## Temas

- [HTML e CSS](./html-css/) — estruturação e apresentação de páginas.
- [JavaScript](./javascript/) — lógica e programação no navegador.
- [Backend](./backend/) — implementação de funcionalidades no servidor.
- [Banco de dados](./banco-de-dados/) — modelagem e consultas.
- [Inteligência artificial](./ia/) — atividades introdutórias relacionadas à área.

Ao propor uma solução, inclua contexto suficiente para que outra pessoa entenda o objetivo e como verificar o resultado.
