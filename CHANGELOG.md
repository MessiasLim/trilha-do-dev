# Histórico de alterações

Este arquivo registra mudanças relevantes no TrilhaDoDev em ordem cronológica inversa. As alterações ainda não publicadas ficam em `Não lançado`.

## Atualizações

## 17/07/2026

### Adicionado

- README principal ampliado com navegação, apresentação do projeto, público-alvo, guia rápido, percurso sugerido, FAQ, agradecimentos e canais de contato.
- Seções de documentação sobre trilhas disponíveis, materiais de apoio, estrutura do repositório, contribuição e licença.

### Alterado

- README principal reescrito para refletir a estrutura atual de guias, trilhas, aulas e materiais de apoio.
- CONTRIBUTING atualizado com links válidos, fluxo de contribuição, padrões de conteúdo e checklist de pull request.
- READMEs de Frontend e de Fundamentos atualizados para apontar para os diretórios e conteúdos atuais.
- Aulas de HTML movidas de `Trilhas/Frontend/Fundamentos/html/` para `Trilhas/Frontend/Fundamentos/HTML/`.
- Aulas de CSS movidas de `Trilhas/Frontend/Fundamentos/css/` para `Trilhas/Frontend/Fundamentos/CSS/`.
- Conteúdo de JavaScript reorganizado de `Trilhas/Frontend/Fundamentos/JavaScript/` para `Trilhas/Linguagens/JavaScript/`.
- Estrutura de trilhas reorganizada para separar Frontend, Linguagens, DOM, Java, Python, R e TypeScript.
- Documentação ajustada para distinguir áreas com conteúdo publicado de estruturas que ainda estão em expansão.
- Changelog atualizado para registrar a reorganização do projeto e as melhorias na documentação.

### Corrigido

- Referências incorretas a `Atualizacoes.md`, `CHANCELOG.md`, templates antigos e caminhos inexistentes foram removidas ou corrigidas.
- Links de navegação, contribuição, trilhas, aulas e materiais de apoio corrigidos no README principal.

### Removido

- Arquivo `Atualizacoes.md`, substituído pelo `CHANGELOG.md`.
- READMEs e arquivos vazios de estruturas antigas em `Projetos/`, incluindo os diretórios de projetos iniciante, intermediário e avançado.
- Arquivos vazios de `Img/banners/` e os templates antigos em `TEMPLATE/`, consolidados no modelo atual de conteúdo.
- Diretórios antigos em minúsculas de HTML e CSS após a padronização dos nomes para `HTML/` e `CSS/`.

### Estrutura atual

- A trilha de Frontend contém aulas introdutórias de HTML e CSS e a estrutura inicial de DOM.
- A trilha de Linguagens contém aulas introdutórias de JavaScript.
- As demais áreas mantêm categorias preparadas para receber novos materiais.
