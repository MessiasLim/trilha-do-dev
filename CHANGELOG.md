# Histórico de alterações

Este arquivo registra mudanças relevantes no TrilhaDoDev em ordem cronológica inversa. As alterações ainda não publicadas ficam em `Não lançado`.

## Não lançado

### Alterado

- README principal revisado para refletir a estrutura atual de guias e trilhas.
- CONTRIBUTING atualizado com links válidos, fluxo de contribuição, padrões de conteúdo e checklist de pull request.
- Referências de fundamentos de Frontend alinhadas aos diretórios `HTML/`, `CSS/` e `DOM/`.
- Documentação ajustada para distinguir áreas com conteúdo publicado de estruturas que ainda estão em expansão.

### Corrigido

- Referências incorretas a `Atualizacoes.md`, `CHANCELOG.md` e caminhos inexistentes foram removidas ou corrigidas.

### Estrutura atual

- A trilha de Frontend contém aulas introdutórias de HTML e CSS e a estrutura inicial de DOM.
- A trilha de Linguagens contém aulas introdutórias de JavaScript.
- As demais áreas mantêm categorias preparadas para receber novos materiais.

## 17/07/2026

### Adicionado

- Estrutura inicial para organizar guias, trilhas de estudo e recursos do projeto.
- Páginas de orientação para áreas e categorias de conteúdo.
- Modelos para padronizar novos módulos, projetos e exercícios.
