# Modelo para novos conteúdos

Use este documento como orientação ao criar aulas, módulos, exercícios ou projetos no TrilhaDoDev. Adapte as seções ao tipo de material e remova as que não forem necessárias.

## Princípios

- Dê ao conteúdo um nome claro e mantenha-o na pasta correspondente.
- Explique o objetivo e os pré-requisitos.
- Apresente conceitos em uma sequência fácil de acompanhar.
- Use exemplos próprios, funcionais e relacionados ao tema.
- Inclua referências confiáveis e revise os links.
- Prefira linguagem acessível e explique termos técnicos.

## Estrutura sugerida para um módulo

```markdown
# Título do módulo

## Objetivo
O que a pessoa será capaz de entender ou fazer ao concluir este material?

## Pré-requisitos
- Conhecimentos necessários, se houver.

## Conteúdo
Explique os conceitos em seções curtas e ordenadas.

## Exemplo prático
Apresente um exemplo e explique como ele funciona.

## Exercícios
Proponha atividades para praticar o conteúdo.

## Resumo
Recapitule os pontos principais.

## Referências
- [Título da referência](URL)
```

## Estrutura sugerida para um projeto

```markdown
# Nome do projeto

## Objetivo
Descreva o que será construído e o que será praticado.

## Requisitos
Liste as funcionalidades e restrições do projeto.

## Etapas sugeridas
Divida o trabalho em entregas pequenas.

## Critérios de conclusão
Explique como verificar que o projeto atende aos requisitos.

## Desafios extras
Sugira melhorias opcionais.
```

## Estrutura sugerida para um exercício

```markdown
# Nome do exercício

## Objetivo
Explique a habilidade que será praticada.

## Enunciado
Descreva a tarefa com clareza.

## Requisitos
- Liste as condições que a solução deve atender.

## Como validar
Descreva exemplos de entrada e o resultado esperado, quando aplicável.

## Dica
Inclua uma pista sem entregar a solução completa.
```
