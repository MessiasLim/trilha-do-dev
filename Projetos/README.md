# Projetos

Esta pasta organiza propostas de projetos práticos por nível de experiência. Use os projetos para aplicar conceitos, praticar a resolução de problemas e construir um portfólio.

## Níveis

- [Iniciante](./Iniciante/) — primeiros projetos para praticar fundamentos.
- [Intermediário](./Intermediario/) — projetos que combinam mais recursos e etapas.
- [Avançado](./Avancado/) — desafios maiores, com arquitetura e integração entre componentes.

Comece pelo nível que corresponde ao seu momento de estudo. Antes de implementar, leia o enunciado do projeto, divida o trabalho em etapas e registre as decisões relevantes.
