# Trilha de Backend

Backend é a parte de uma aplicação responsável por processar regras, disponibilizar serviços e se comunicar com outros sistemas. Esta trilha agrupa fundamentos, linguagens, frameworks e APIs.

## Organização

- `Fundamentos/` — lógica de programação e linguagens usadas no servidor.
- `Frameworks/` — ferramentas e frameworks para implementar aplicações backend.
- `APIs/` — estilos de interface e integração entre aplicações, como REST, GraphQL e webhooks.

Aprenda primeiro lógica, HTTP e os fundamentos da linguagem escolhida. Depois, pratique criando serviços pequenos e integrando-os com uma interface ou banco de dados.
