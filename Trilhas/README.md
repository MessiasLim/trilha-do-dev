# Trilhas de estudo

As trilhas organizam os conteúdos por área de desenvolvimento. Cada pasta pode conter fundamentos, ferramentas, tecnologias e materiais práticos relacionados.

## Áreas

- [Frontend](./Frontend/README.md) — interfaces e aplicações executadas no navegador.
- [Backend](./Backend/README.md) — lógica e serviços executados no servidor.
- [Banco de dados](./Banco-de-dados/README.md) — armazenamento, consulta e modelagem de dados.
- [DevOps](./DevOps/README.md) — infraestrutura, automação e entrega de software.
- [Mobile](./Mobile/README.md) — desenvolvimento para dispositivos móveis.
- [Games](./Games/README.md) — desenvolvimento de jogos e fundamentos de game design.
- [Inteligência artificial](./IA/README.md) — conceitos e aplicações de IA.
- [Data Science](./Data-Science/README.md) — análise e visualização de dados.
- [Testes](./Testes/README.md) — práticas de qualidade e validação de software.

Você pode estudar uma área por vez ou combinar trilhas conforme os objetivos dos seus projetos. Para começar, consulte os [guias de estudo](../Guias/README.md).
