# Trilha de Inteligência Artificial

Esta trilha reúne conceitos e práticas para compreender sistemas de inteligência artificial e explorar suas aplicações de forma responsável.

## Assuntos

- `Fundamentos/` — conceitos básicos e vocabulário da área.
- `Python-IA/` — uso de Python em atividades relacionadas à IA.
- `Machine-Learning/` e `Deep-Learning/` — métodos de aprendizagem de máquina.
- `Prompt-Engineering/` — elaboração e avaliação de instruções para modelos.
- `IA-Gerativa/` — sistemas que geram texto, imagens ou outros conteúdos.

Estude os fundamentos antes de avançar para modelos e ferramentas. Avalie limitações, qualidade dos dados, privacidade e possíveis vieses ao usar sistemas de IA.
