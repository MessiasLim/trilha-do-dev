# Trilha de Desenvolvimento Mobile

Esta trilha reúne tecnologias e conceitos para criar aplicações voltadas a celulares e outros dispositivos móveis.

## Tecnologias

- `React-Native/` — desenvolvimento multiplataforma com JavaScript ou TypeScript.
- `Flutter/` — desenvolvimento multiplataforma com Flutter e Dart.
- `Kotlin/` — desenvolvimento para Android.
- `Swift/` — desenvolvimento para plataformas Apple.

Antes de escolher uma tecnologia, considere as plataformas que deseja atender e os conhecimentos que já possui. Pratique também conceitos de interfaces, navegação, acessibilidade e ciclo de vida de aplicações.
