# Trilha de Data Science

Data Science combina programação, estatística e conhecimento do domínio para explorar dados e comunicar resultados.

## Assuntos

- `Python/` — linguagem e ambiente comuns para análise de dados.
- `Pandas/` e `NumPy/` — ferramentas para manipulação e cálculo.
- `Visualizacao/` — representação visual e comunicação de resultados.

Uma prática recomendada é começar com uma pergunta, explorar os dados disponíveis, documentar as transformações e apresentar conclusões com suas limitações.
