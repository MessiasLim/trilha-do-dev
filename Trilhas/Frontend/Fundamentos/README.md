# Fundamentos de Frontend

Esta seção reúne os conhecimentos básicos usados para estruturar, estilizar e programar páginas web.

## Conteúdos

- `html/` — estrutura e semântica de documentos web.
- `css/` — estilos, layout e adaptação a diferentes telas.
- `javascript/` — programação e comportamento interativo.
- `typescript/` — tipagem estática aplicada ao JavaScript.

Estude os conceitos, pratique com pequenos exemplos e combine as tecnologias em páginas próprias. A seção também pode receber materiais introdutórios relacionados a acessibilidade e boas práticas web.
