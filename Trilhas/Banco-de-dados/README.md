# Trilha de Banco de Dados

Esta trilha apresenta formas de modelar, armazenar, consultar e administrar dados usados por aplicações.

## Tecnologias e assuntos

- `SQL/` — conceitos de bancos relacionais e linguagem de consulta.
- `PostgreSQL/` e `MySQL/` — bancos de dados relacionais.
- `MongoDB/` — banco de dados orientado a documentos.
- `Redis/` — armazenamento em memória e estruturas de dados.
- `Prisma/` — ferramenta de acesso a dados para aplicações.

Comece pelos conceitos de tabelas, documentos, relacionamentos, consultas e integridade dos dados. A escolha de uma tecnologia deve considerar os requisitos do projeto.
