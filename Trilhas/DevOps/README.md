# Trilha de DevOps

DevOps reúne práticas para aproximar desenvolvimento e operações, automatizar tarefas e entregar software com mais consistência.

## Assuntos

- `Linux/` — sistema operacional e ferramentas de linha de comando.
- `Docker/` e `Kubernetes/` — containers e orquestração.
- `CI-CD/` e `GitHub-Actions/` — integração e entrega contínuas.
- `Terraform/` — infraestrutura definida como código.
- `Cloud/` — serviços de nuvem, incluindo AWS, Azure e GCP.

Os temas dependem uns dos outros em diferentes graus. Uma base de Linux, redes e Git ajuda antes de avançar para containers, automação e nuvem.
